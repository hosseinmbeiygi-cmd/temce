## فاز ۰ — جمع‌آوری و آماده‌سازی داده‌ها

### ۰-۱. داده‌های سالانه (برای تحقیق علّی)
- دوره: ۱۳۴۰ تا ۱۳۷۹ (۴۰ سال)
- تبدیل متغیرها به لگاریتم طبیعی

### ۰-۲. داده‌های روزانه/ماهانه (برای پیش‌بینی)

## فاز ۱ — شناسایی عوامل موثر (تحقیق علّی)

> **(بر اساس مقاله شریف‌زاده و حقیقت)**

### ۱-۱. آزمون ریشه واحد
| روش | هدف |
|-----|-----|
| ADF تعمیم‌یافته | تعیین I(0) یا I(1) |
| پرون | بررسی شکست ساختاری |

**نتایج مورد انتظار:** تمام متغیرها I(1) هستند (بجز PROD که I(0) است)

### ۱-۲. تخمین مدل‌های چهارگانه

#### معادله نرخ اسمی ارز (NER)
```
NER = -190.40 - 0.08×MRAT(-1) - 0.11×MRAT - 0.08×MRAT + 0.003×POIL
      + 660.55×G - 15.24×GDP + 9.57×I - 10.27×TOT + 0.02×P + 0.06×PGOLD
```

#### معادله نرخ حقیقی ارز (RER)
```
RER = +988.69 + 0.045×MRAT(-1) + 0.052×MRAT + 0.002×GDP
      - 71.64×BR - 11.26×POIL + 876.54×OPN - 279.79×TOT
      - 0.016×PROD + 12.48×PGOLD
```

#### معادله لگاریتم نرخ اسمی ارز (LNER)
```
LNER = -0.019 - 1.006×DM - 1.455×DM1 - 0.982×DM2
       + 0.068×BR - 0.401×LI + 0.776×LGDP + 0.256×LPGOLD
```

#### معادله لگاریتم نرخ حقیقی ارز (LRER)
```
LRER = 7.960 + 1.567×LG - 0.365×LPOIL + 0.164×BR - 0.563×LI - 1.170×LGDP
```

### ۱-۳. آزمون همگرایی
| روش | معیار تصمیم |
|-----|-----------|
| AEG | آماره ADF پسماند < مقدار بحرانی ۵٪ |
| CRDW | DW > ۰.۵۱۱ |
| یوهانسن | انتخاب بردارها با معیار بهمنی اسکوئی-بروکس |

### ۱-۴. نتایج کلیدی
| نظریه | وضعیت |
|-------|-------|
| پولگراها | ❌ رد شد |
| PPP | ❌ رد شد |
| اثر قیمت نفت بر RER | ✅ تأیید (منفی و معنادار) |
| اثر سرمایه‌گذاری خصوصی | ✅ تأیید (منفی) |

## فاز ۲ — مدل‌سازی و پیش‌بینی قیمت دلار

> **(جدید: فراتر از مقاله اصلی)**

### ۲-۱. انتخاب مدل پیش‌بینی

| مدل | مناسب برای | مزیت |
|-----|-----------|-------|
| **VAR/VECM** | داده‌های سری زمانی با همگرایی | استفاده از روابط بلندمدت |
| **ARIMA/SARIMA** | پیش‌بینی خودتوصیفی | ساده و سریع |
| **LSTM** | الگوهای غیرخطی | یادگیری عمیق |
| **XGBoost** | متغیرهای زیاد | مقاوم در برابر نویز |
| **Prophet** | روند + فصلی + شوک‌ها | مدیریت تعطیلات و رویدادها |

### ۲-۲. پیشنهاد: مدل ترکیبی (Ensemble)

```
پیش‌بینی نهایی = α₁×VAR + α₂×LSTM + α₃×XGBoost
```

权重 بر اساس دقت پیش‌بینی هر مدل در بازه اعتبارسنجی تعیین می‌شود.

### ۲-۳. ویژگی‌های (Features) ورودی مدل

#### ویژگی‌های اقتصاد کلان
| ویژگی | توضیح |
|-------|-------|
| نرخ تورم ماهانه | تغییرات CPI |
| حجم پول M2 | رشد نقدینگی |
| نرخ سود بین‌بانکی | هزینه فرصت نگهداری ریال |
| ذخایر ارزی | توانایی بانک مرکزی در کنترل نرخ ارز |
| درآمد نفتی | منبع اصلی عرضه ارز |
| تراز تجاری | خالص صادرات و واردات |
| GDP فصلی | وضعیت اقتصاد واقعی |

#### ویژگی‌های بازارهای جایگزین
| ویژگی | توضیح |
|-------|-------|
| قیمت نفت برنت | تأثیر مستقیم بر درآمد ارزی |
| قیمت طلای جهانی | جایگزین ارز |
| قیمت سکه داخلی | سیگنال بازار |
| شاخص بورس | جریان سرمایه |
| نرخ دلار در بازارهای همسایه | آربیتراژ |

#### ویژگی‌های زمانی
| ویژگی | توضیح |
|-------|-------|
| ماه سال | فصلیت (مثلاً پایان سال مالی) |
| روز هفته | تعطیلات و تعاملات بین‌المللی |
| متغیرهای دامی تحریم | ۱=دوره تحریم، ۰=غیرتحریم |
| متغیرهای دامی شوک سیاسی | جنگ، انتخابات، مذاکرات هسته‌ای |

#### ویژگی‌های تکنیکال
| ویژگی | توضیح |
|-------|-------|
| میانگین متحرک ۷/۲۱/۵۰/۲۰۰ روزه | روند |
| RSI (۱۴ روزه) | اشباع خرید/فروش |
| MACD | سیگنال تغییر روند |
| Bollinger Bands | نوسانات |
| حجم معاملات | قدرت روند |

### ۲-۴. معماری مدل پیش‌بینی

```
┌─────────────────────────────────────────────────┐
│                لایه جمع‌آوری داده               │
│  بانک مرکزی │ OPEC │ بازار سهام │ اخبار │ API  │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│              لایه پیش‌پردازش                     │

└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│              لایه مدل‌سازی (Ensemble)            │
│  ┌─────┐  ┌──────┐  ┌─────────┐  ┌──────────┐  │
│  │ VAR │  │ LSTM │  │ XGBoost │  │ Prophet  │  │
│  └──┬──┘  └──┬───┘  └────┬────┘  └────┬─────┘  │
│     └────────┴───────────┴────────────┘         │

└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│              لایه خروجی                         │
│  قیمت پیش‌بینی │ ا Confidence Interval │ نمودار│

```

### ۲-۵. ارزیابی مدل

| معیار | فرمول |
|-------|-------|
| MAE | میانگین خطای مطلق |
| RMSE | جذر میانگین مربعات خطا |
| MAPE | درصد خطای مطلق |
| R² | ضریب توضیح |

**شیوه اعتبارسنجی:**
- **Walk-forward validation**: آموزش روی داده‌های گذشته، پیش‌بینی یک دوره جلوتر
- **تقسیم داده**: ۸۰٪ آموزش، ۲۰٪ تست (بدون data leakage)
