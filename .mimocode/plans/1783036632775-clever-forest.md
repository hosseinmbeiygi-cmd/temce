## Step 1: Create Indicator Computation Functions

**File: `src/indicators/trend_momentum.py`** (new file)

Three pure functions (no side effects, same pattern as `src/indicators/general.py`):

### `calculate_half_trend(high, low, close, amplitude=2, channel_deviation=2)`
- Uses ATR-based channel to determine trend direction
- Returns dict: `{"trend": 1/-1, "half_trend_line": float, "buy_signal": bool, "sell_signal": bool}`
- Logic:
  - Compute ATR over `amplitude` period
  - Upper/Lower channel = EMA(close) ± channel_deviation * ATR
  - If close > upper channel → trend = 1 (up), if close < lower channel → trend = -1 (down)
  - Buy signal: trend flips from -1 to 1, Sell signal: trend flips from 1 to -1

### `calculate_squeeze_momentum(high, low, close, bb_period=20, bb_std=2.0, kc_period=20, kc_mult=1.5)`
- Bollinger Bands inside Keltner Channels = squeeze (low volatility)
- Returns dict: `{"squeeze_on": bool, "momentum_value": float, "momentum_positive": bool}`
- Logic:
  - BB = SMA ± std * BB_std
  - KC = EMA ± ATR * kc_mult
  - Squeeze on: lower BB > lower KC AND upper BB < upper KC
  - Momentum = Linear Regression(close - midline, length=bb_period)

### `calculate_support_resistance(high, low, close, lookback=20, volume=None, vol_threshold=1.5)`
- Finds swing highs/lows as S/R levels, detects breaks with volume confirmation
- Returns dict: `{"support": float, "resistance": float, "break_up": bool, "break_down": bool, "pullback": bool}`
- Logic:
  - Support = min(low[-lookback:]), Resistance = max(high[-lookback:])
  - Break up: close > resistance AND (volume is None OR volume > vol_threshold * avg_volume)
  - Break down: close < support AND same volume condition
  - Pullback: price broke level then returned to it

## Step 3: Create Backtest Strategies

**3 new files in `backtesting/strategies/rule_based/`:**

### `half_trend_strategy.py`
- Extends `BaseStrategy`
- Uses `calculate_half_trend` on each bar
- Buy when buy_signal=True and position<=0, Sell when sell_signal=True and position>=0

### `squeeze_momentum_strategy.py`
- Extends `BaseStrategy`
- Maintains rolling OHLCV window (20 bars)
- Buy when squeeze_on turns off AND momentum_positive=True, Sell when momentum turns negative

### `support_resistance_strategy.py`
- Extends `BaseStrategy`
- Maintains rolling window for S/R calculation
- Buy on break_up (close > resistance with volume), Sell on break_down or pullback
