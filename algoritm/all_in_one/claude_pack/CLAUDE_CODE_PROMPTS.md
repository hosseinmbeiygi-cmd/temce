# CLAUDE_CODE_PROMPTS — پرامپت هر گام اصلاح برای Claude Code

> استفاده: هر گام را در یک **جلسه‌ی جدید** بدهید. بعد از پایان، گزارش را بخوانید و فقط پس از تأیید خودتان گام بعد را شروع کنید.
> همه‌ی پرامپت‌ها این بلوک مشترک را اول دارند (کپی کنید بالای هر پرامپت). قالب گزارش پایان هر گام: «قالب گزارش» انتهای `PHASES_AND_PROMPTS.md`.

## بلوک مشترک (بالای هر پرامپت)
```
ابتدا بخوان به این ترتیب: CLAUDE.md (با CLAUDE_ADDENDUM اضافه‌شده)، AUDIT_STAGE0.md، بخش همین گام در
REMEDIATION_PLAN.md، SPEC مرجع همین گام، گزارش گام قبل (اگر هست).
قواعد: (۱) هر یافته‌ی ممیزی را قبل از اقدام خودت بازتأیید کن (فایل:خط + اجرای کوچک)؛ اگر نخواند گزارش کن
و پیش نرو. (۲) اول تست بنویس (تستی که باگ را نشان دهد)، بعد اصلاح. (۳) روی فایل‌های موجود مستقیم
ویرایش/حذف نکن؛ patch (diff) در patches/ بگذار. کد جدید در src/ و tests/. (۴) DB فقط‌خواندنی؛ migration فقط
فایل SQL پیشنهادی. (۵) هرگز .env* را نخوان و مقدار رمز را چاپ نکن. (۶) عدد/ستون/API را از حافظه نساز؛
بر نمونه‌ی واقعی یا اسناد تکیه کن؛ نامعلوم = TODO(verify)/TODO(source). (۷) نتیجه‌ی ضعیف ولی صادق را گزارش کن.
(۸) همه‌ی اجراها با run_manifest در experiments/. (۹) پایان گام: قالب گزارش، سپس توقف؛ گام بعد را شروع نکن.
```
