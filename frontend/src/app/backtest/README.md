# 📊 راهنمای بک‌تست استراتژی

سیستم بک‌تست برای ارزیابی استراتژی‌های معاملاتی روی داده‌های تاریخی بازار سرمایه ایران.

---

## 🚀 شروع سریع

1. **انتخاب نماد(ها)** — از باکس جستجو، نمادهای مورد نظر را انتخاب کنید
2. **انتخاب استراتژی** — از dropdown استراتژی مناسب را انتخاب کنید
3. **تنظیم پارامترها** — پارامترهای استراتژی، بازه زمانی و سرمایه اولیه را تنظیم کنید
4. **اجرا** — دکمه "اجرای بک‌تست" را بزنید

---

## 🧩 ویژگی‌ها

### بک‌تست تکی
شبیه‌سازی یک استراتژی روی یک یا چند نماد با جزئیات کامل:
- منحنی سرمایه
- نمودار افت سرمایه (Drawdown)
- معیارهای عملکرد (شارپ، بازده، وین‌ریت و...)
- کیفیت داده

### بک‌تست همه نمادها
اجرای همزمان یک استراتژی روی ۱۰۰۰+ نماد با کنترل هم‌زمانی و تایم‌اوت

### مقایسه استراتژی‌ها
اجرای همه استراتژی‌ها روی یک نماد و مقایسه بصری با:
- نمودار راداری
- جدول مقایسه‌ای
- Deflated Sharpe Ratio
- ذخیره و بارگذاری تاریخچه مقایسه‌ها

### ابزارهای پیشرفته
- **🧬 موتور کشف استراتژی** (/backtest/engine) — آبشار فیلترهای چندمرحله‌ای
- **🚀 تولید خودکار استراتژی** (/backtest/generate) — جستجوی ترکیبی + ژنتیک
- **📊 Walk-Forward** (/backtest/walk-forward) — اعتبارسنجی پنجره‌گردان
- **🎲 Monte Carlo** (/backtest/monte-carlo) — شبیه‌سازی مونت کارلو

---

## ⚙️ تنظیمات پیشرفته

| پارامتر | توضیح | پیش‌فرض |
|---------|-------|---------|
| کارمزد | درصد کارمزد هر معامله (مثلاً ۰.۳۵ = ۰.۳۵٪) | ۰.۳۵٪ |
| Slippage | لغزش قیمت بر حسب بی‌پی‌اس | ۱۰ bps |
| روش محاسبه تعداد | Fixed / درصد سرمایه / کلی / مبتنی بر ریسک | Fixed |
| حد ضرر | درصد حد ضرر (اختیاری) | — |
| حد سود | درصد حد سود (اختیاری) | — |

---

## 📈 معیارهای عملکرد

| معیار | توضیح |
|-------|-------|
| بازده کل | درصد تغییر ارزش پرتفوی از ابتدا تا انتها |
| بازده سالانه | CAGR |
| شارپ | نسبت بازده به ریسک (بیشتر از ۱ = عالی) |
| Max DD | حداکثر افت سرمایه |
| Win Rate | درصد معاملات برنده |
| آلفا | بازده اضافی نسبت به بازار |
| بتا | حساسیت به بازار |

## 🗄️ داده‌های تاریخی

سیستم از سه منبع داده پشتیبانی می‌کند:
1. **brsapi_historical_daily** — داده‌های روزانه چندساله (۱۰۰۰+ نماد)
2. **brsapi_intraday_trades** — داده‌های ریزمعاملات (یک ماه اخیر)
3. **quotes** — نقل قول‌های وارداتی

ترتیب اولویت: `historical_daily` ← `quotes` (در صورت نبود داده)

## 🐛 رفع باگ‌های انجام‌شده

- **ثابت:** متغیر `is_synthetic` تعریف‌نشده (باعث کرش همه بک‌تست‌ها می‌شد)
- **ثابت:** `slippage_bps` و `commission_pct` در بک‌تست چندنمادی ارسال نمی‌شد
- **ثابت:** `save_compare_result` کامیت نمی‌شد (داده تاریخچه از بین می‌رفت)
- **ثابت:** نشت حافظه در کش `_runs` (اکنون محدود به ۵۰۰ رکورد)
- **ثابت:** Walk-Forward و Monte Carlo سرویس بدون وابستگی می‌ساختند
- **ثابت:** `run-all` بدون تایم‌اوت (اکنون ۱۰ دقیقه محدودیت)
- **ثابت:** `commission_pct` و `slippage_bps` در محاسبات Broker نادیده گرفته می‌شدند
- **ثابت:** Deflated Sharpe جای best/worst را عوض می‌کرد
- **ثابت:** اعتبارسنجی تاریخ شمسی (ورودی نادرست باعث `null` می‌شد)
- **ثابت:** تایپ mismatch در پاسخ‌های API

## 🛡️ محدودیت‌ها و هشدارها

- **کارمزد و مالیات:** مدل کارمزد بورس ایران (خرید ۰.۵٪ + فروش ۰.۵٪ + مالیات ۰.۵٪)
- **دقت شبیه‌سازی:** وابسته به کیفیت و دقت داده‌های ورودی
- **Overfitting:** استفاده از Walk-Forward و Deflated Sharpe برای جلوگیری از بیش‌برازش
- **Liquidity:** مدل لغزش قیمت بر اساس حجم معاملات واقعی
- **رژیم بازار:** سیستم به صورت خودکار رژیم بازار (صعودی/نوسانی/نزولی) را تشخیص می‌دهد
