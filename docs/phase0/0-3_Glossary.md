# 0-3 — واژه‌نامه و ترمینولوژی — فاز صفر

> اصلاح ترجمه سند: «چهار صفحه» → «چهار لایه (Plane)»

| اصطلاح سند | معادل مصوب فارسی | تعریف ۱ جمله‌ای |
|------------|------------------|----------------|
| Plane (Data/Research/Trading/Control) | **لایه** | سطح معماری مستقل با مسئولیت جدا |
| Raw Store | مخزن خام | جدول append-only پاسخ‌های خام با checksum |
| Normalizer | هنجارگر | تبدیل هر منبع به مدل مشترک `instruments/contracts` |
| Instrument Master | فهرست مادر ابزار | جدول یکتای هر نماد با ISIN/بازار/قرارداد |
| Proposal Order | سفارش پیشنهادی | خروجی Risk پس از کنترل‌ها، منتظر تأیید انسانی |
| Approval Gateway | درگاه تأیید | UI/سرویس تأیید/رد/انقضای Proposal با لاگ |
| Broker Adapter | تطبیق‌گر کارگزاری | واسط مستقل ارسال سفارش به کارگزاری با Idempotency |
| Greeks | حساسیت‌ها | Delta/Gamma/Theta/Vega/Rho مشتق قیمت اختیار |
| IV (Implied Volatility) | نوسان ضمنی | نوسانی که قیمت بازار را با BS برابر می‌کند |
| Mid Price | قیمت میانی | `(Bid+Ask)/2` در صورت بازار معتبر |
| Slippage | لغزش | اختلاف قیمت مورد انتظار و اجراشده |
| PCR | نسبت Put به Call | `put_volume / call_volume` |
| Max Pain | بیشترین زیان | قیمتی که بیشترین قرارداد بی‌ارزش می‌شود |
| CVD | تجمیع حجم-قیمت | Cumulative Volume Delta |
| Kill Switch | کلید توقف اضطراری | قطع فوری تمام ارسال‌ها (out-of-band) |
| Circuit Breaker | مدارشکن | توقف خودکار پس از زیان/خطای آستانه |
| Idempotency Key | کلید یکتایی | جلوگیری از اجرای دوباره سفارش |
| RACI | ماتریس مسئولیت | Responsible/Accountable/Consulted/Informed |
| SLA | توافق سطح خدمت | شامل سهمیه، تأخیر، دسترس‌پذیری |
| BCP | تداوم کسب‌وکار | برنامه بازیابی پس از بحران |
