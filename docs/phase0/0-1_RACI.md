## ۲. ماتریس RACI (R=انجام، A=پاسخگو، C=مشورت، I=اطلاع)

| فعالیت / لایه | مدیر پروژه | مالک ریسک | مالک داده | معمار | امنیت | محصول | ممیز | حقوقی |
|---------------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **Data Plane — Raw Store + نگاشت** | I | C | **R/A** | C | I | I | C | I |
| **Data — سهمیه BrsApi + بافر** | I | C | **R/A** | C | C | I | I | I |
| **Research — نسخه‌گذاری محاسبات** | I | C | C | **R** | I | I | **A** | I |
| **Research — قانون قیمت IV** | I | **A** | C | C | I | I | R | I |
| **Research — جدول هزینه/مارجین** | C | **A** | C | C | I | I | R | C |
| **Trading — Risk Engine (۱۲ کنترل)** | I | **A** | I | **R** | C | I | C | C |
| **Trading — Proposal Order** | I | **A** | I | **R** | C | C | C | I |
| **Trading — Approval Gateway** | C | **A** | I | R | C | **R** | C | I |
| **Trading — Paper Trading + دفتر** | I | **A** | C | R | C | C | **R** | I |
| **Broker Adapter + اجرای واقعی** | **A** | **A** | I | **R** | C | I | C | **R** |
| **Control — RBAC/Vault/Audit** | I | C | I | C | **R/A** | I | C | C |
| **Control — Kill Switch / BCP** | **A** | **A** | I | C | **R** | I | C | I |
| **هزینه/بودجه** | **R** | **A** | C | C | I | C | I | C |

> قاعده: هر سطر دقیقاً یک A دارد (پاسخگو). در ردیف‌های Trading، A مشترک مالک ریسک است — یعنی بدون امضای او هیچ سفارشی به Broker نمی‌رود.

## ۳. اختیارات مالک ریسک (کتبی)
- تنها مرجع تعیین سقف سرمایه هر سفارش، زیان روزانه، و allowlist نماد
- تنها مرجع فعال‌سازی/احیاء Kill Switch (حتی مدیرعامل بدون او نمی‌تواند احیاء کند)
- حق وتو ورود به فاز ۳ (اجرای واقعی) — امضای «تأیید کتبی مالک ریسک» در گیت ۳ الزامی است
- جانشین: در غیاب، معاون مالی با سقف ۵۰٪ سقف عادی (کاهش ریسک)

## ۴. معیار پذیرش این سند
- امضای دیجیتال/کاغذی مدیرعامل + مالک ریسک + مدیر پروژه تا ۱۴۰۴/۰۶/۱۰
- انتشار در `docs/phase0/0-1_RACI.md` و ابلاغ به ۸ نقش
