# 3-2 — اجرای محدود ۱ بازار — فاز ۳

> مالک: مدیر پروژه | تأیید: مالک ریسک + حقوقی

## محدوده
- بازار: فقط **اختیار سهام** (۱۰ نماد allowlist)
- حجم: ≤ ۵ سفارش/روز، هر سفارش ≤ ۵۰م ریال (سقف 3-1)
- مدت: ۴ هفته پایلوت

## پیش‌نیاز
- [ ] Broker Adapter تأیید حقوقی + تست بازیابی
- [ ] Kill Switch تست <30s
- [ ] Paper ۲۸ روز بدون bypass

## چک‌لیست هر سفارش واقعی
1. Signal → Risk (۱۲ کنترل) → Proposal (TTL 5m)
2. Approval Gateway (MFA) → لاگ
3. Broker.send (idempotent) → حالات `accepted/partial/filled`
4. دفتر به‌روز + انطباق

## معیار خروج
- ۲۰ سفارش واقعی بدون حادثه + زیان ≤ سقف + گزارش مالک ریسک
- در صورت حادثه → Kill Switch + گزارش ریشه‌یابی
