## 6. تصمیم‌های بسته‌شده در این فاز (برای جلوگیری از بازگشت)

1. **fail-closed داده:** مقدار غایب = `null` + `data_gaps`، نه صفر (در Phase 1/2 پیاده و تست شده).
2. **واحد پول:** ریال به‌عنوان واحد پیش‌فرض پاسخ‌های gold؛ `_usd` برای استثناها.
3. **عدم سطح معامله:** هیچ endpoint سفارش/کیف پول/تحویل در دامنه gold؛ تست `test_phase2_routes_are_read_only_and_never_trade`.
4. **secret management:** `.env` track نمی‌شود؛ compose با `${VAR:?}` fail-closed؛ salt توکن اجباری.
5. **مالکیت:** هر فایل یک مالک اصلی؛ تغییر مشترک با ثبت تصمیم (WORK_OWNERSHIP).
6. **صداقت گزارش:** هیچ «سبز» بدون خروجی فرمان ثبت نمی‌شود؛ ادعای handoff بدون بازتولید، «تأییدنشده» علامت می‌خورد.
