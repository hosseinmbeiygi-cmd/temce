## 3. نمایش داده و وضعیت‌ها

- `EmptyState` مشترک در `components/dashboard/primitives.tsx:243` و استفاده در گزارش/داشبورد.
- `DataTrustBadge` چهار حالت `LIVE/DELAYED/SAMPLE/NO_DATA` دارد؛ مقدار ناشناخته → `DELAYED` (fail-closed) (`DataTrustBadge.tsx:28-38`).

## 4. الگوهای مشکوک (نیازمند فاز ۲)

| الگو | تعداد | حکم |
|---|---|---|
| `key={i}` / `key={index}` | **۲۲۴** | **مشکوک**؛ در لیست‌های استاتیک بی‌خطر، در لیست سورت/فیلترشده باعث رندر اشتباه می‌شود. فهرست کامل بررسی نشد. |
| `alert(...)` | **۱۰** خط: ۶ در کد محصول (economic-calendar ۲، gold/settings ۲، paper-trading ۲) + ۴ در فایل تست | **تأییدشده به‌عنوان UX نامناسب**؛ `alert` محصول ترد اصلی را بلوکه می‌کند. |
| `<img>` به‌جای `next/image` | **۱۱** (بیشتر crypto/settings) | **مشکوک عملکردی**؛ اثر LCP اندازه‌گیری نشد. |
| `dangerouslySetInnerHTML` | **۱** | theme script در `app/layout.tsx:109` با `nonce` — قابل قبول؛ باید ثابت بماند. |
| `: any` در TS | **۰** | خوب. |
| `console.log` | **۴** | کم؛ باید در production حذف/pino شود. |
| virtualization | **۰** | **ریسک عملکرد** برای جدول‌های بزرگ. |
| `new Date()` در فایل tsx | **۳۸** | **مشکوک** به ناسازگاری hydration؛ همه موارد بازبینی نشد. |

> تعداد ۲۲۴ برای `key={i}` از grep خام است و به‌تنهایی باگ نیست؛ به‌عنوان فهرست بررسی فاز ۲ ثبت می‌شود، نه ۲۲۴ باگ.
