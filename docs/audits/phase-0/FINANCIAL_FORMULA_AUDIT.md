# ممیزی فرمول‌های مالی — فاز صفر

**اصل:** وجود تابع و تولید عدد، اثبات صحت نیست. هر فرمول با یک محاسبه مستقل (یا تعریف مرجع) مقایسه شد. جایی که مرجع رسمی در repo نبود، «اعتبارسنجی‌نشده» علامت خورده و حدس زده نشده است.

**روش:** اجرای اسکریپت مقایسه‌ای در `venv` (Python 3.11.9) با پیاده‌سازی مستقل فرمول (بدون استفاده از همان تابع)؛ خروجی‌های عددی زیر واقعی‌اند.

## 2. فرمول‌های دارای ایراد تأییدشده

### F-20 — نوسان ضمنی در سررسید صفر

- **فایل:** `domain/options/pricing.py:159-202`
- **شاهد اجرایی:**
  ```
  T=0.0  → ZeroDivisionError: float division by zero
  T=1e-12 → 125413.555780698  (بدون هیچ سقف/همگرایی)
  ```
- **اثر:** در روز سررسید، تحلیل نوسان (`services/options_analytics.VolatilityAnalyzer`) با ۵۰۰ می‌شکند؛ برای T نزدیک صفر عدد بی‌معنا برمی‌گردد.
- **مالک:** ۱ · **ISSUE-102** · **وضعیت:** تأییدشده.

### F-21 — مارجین covered call با `contract_size` پیش‌فرض سهام

- **فایل:** `domain/options/margin_engine.py:35-45,128-134`
- **شاهد اجرایی:**
  ```
  1,000 shares + 10 short calls (size 1000) → strategy=covered_call, margin=0.0
  same with stock contract_size=1            → strategy=multi_leg,  margin=800,000
  ```
- **اثر:** پوزیشن پوشش‌نشده، مارجین صفر می‌گیرد.
- **مالک:** ۱ · **ISSUE-101** · **وضعیت:** تأییدشده.

### F-22 — قرارداد واحد VaR

- **فایل:** `domain/options/var_calculator.py`
- **مشکل:** docstring ورودی را «درصد روزانه» می‌داند؛ `var_95 = var_95_pct × portfolio_value` بدون تقسیم بر ۱۰۰. اگر ورودی درصد باشد، نتیجه ۱۰۰ برابر می‌شود. `monte_carlo_var` ورودی `mu/sigma` را سالانه فرض و بر ۲۵۲ تقسیم می‌کند، در حالی که `parametric_var` روزانه است.
- **شاهد:** خواندن کد + پارامترهای متفاوت؛ هیچ مصرف‌کننده API برای تعیین قطعی واحد پیدا نشد.
- **مالک:** ۱+۳ · **ISSUE-103** · **وضعیت:** نیازمند تصمیم (D-02).

### F-23 — نبود `cvar_95_pct` در `VaRResult`

- **شاهد:** `hasattr(res, "cvar_95_pct") == False`؛ فقط `cvar_95` (مبلغ) موجود است، در حالی که `var_95_pct` و `var_99_pct` وجود دارند.
- **اثر:** مصرف‌کننده نمی‌تواند CVaR درصدی را بدون تقسیم دستی بگیرد؛ قرارداد نامتقارن.
- **مالک:** ۱ · **ISSUE-103** (افزودنی) · **وضعیت:** تأییدشده.
