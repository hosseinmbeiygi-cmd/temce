# انطباق سند مادر IGQP با کد — بررسی مبتنی بر شاهد

> **این فایل چیست:** «سند مادر ترمینال IGQP» مرجع هنجاری شماست (فرمول‌ها، کارمزد، تسویه،
> چک‌لیست‌ها). این سند، متن سند مادر را **تکرار نمی‌کند**؛ بلکه برای هر بندِ قابل‌آزمون آن
> می‌گوید در همین مخزن **پیاده شده / ناقص / وجود ندارد** — با مسیر فایل و شمارهٔ خط.
> تاریخ: ۱۴۰۵/۰۷/۲۲ (2026-10-14).
>
> **روش:** هر ادعا با `grep`/خواندن فایل روی working tree فعلی تأیید شده. هر موردی که
> پیدا نشد، صریح «یافت نشد» علامت خورده — نه «فرض می‌شود هست».

## ۱۲. آنچه سند مادر و سند تجمیعی باید به آن ارجاع دهند

- **سند تجمیعی** (`docs/GOLD_SILVER_ASSISTANT_SPEC.md`) بخش ۶ (موتورهای تحلیلی) باید به
  **شناسه‌های F-01…F-16 همین سند مادر** ارجاع دهد تا هر فرمول یک مرجع واحد داشته باشد.
- گیت‌های بخش ۷ سند تجمیعی (ریزساختار، نقدشوندگی) تا پیاده‌سازی F-04/F-05 نمی‌توانند
  واقعاً اجرا شوند — باید به‌عنوان «گیت غیرفعال / اطلاعات ناکافی» رفتار کنند، نه «سبز».
- بانک سناریو (`core/scenario_bank`) باید برای فرمول‌های پیاده‌شده سناریو داشته باشد و برای
  پیاده‌نشده‌ها `mode="refuse"`/«اطلاعات ناکافی» — چون پاسخ‌دادن با دادهٔ ناموجود ممنوع است.
